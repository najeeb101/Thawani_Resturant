# Thawani Restaurant & Cafe

Bilingual (English / Arabic) website for Thawani Restaurant & Cafe in Doha, Qatar.

**Live:** https://najeeb101.github.io/Thawani_Resturant/

## Features
- English and Arabic with a full right-to-left layout, switchable from the nav
- Dark and light themes
- Menu page with categories
- Static HTML, CSS and JavaScript: no build step, no framework

## Structure
```
index.html        Home: hero, about, stats, hours and contact
menu.html         Full menu
css/              One stylesheet per section, theme tokens in variables.css
js/               Language switching, theme toggle, navigation
assets/images/    Logo, favicon, photos
```

## Run locally
Open `index.html` in a browser, or serve the folder:
```bash
npx serve .
```

## Deploy
GitHub Pages serves the `main` branch.
